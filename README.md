# Zigbox Homebrew tap

```
brew install zigbox/tap/zigbox
```

Installs `zbx`, the [Zigbox](https://github.com/Zigbox/zigbox) container runtime, for macOS on Apple Silicon. The first `zbx run` boots a small Linux VM through Apple's Virtualization.framework, with no setup step and no administrator password.

The formula installs the prebuilt binary from the Zigbox/zigbox GitHub release. That binary is signed with Developer ID and notarized by Apple. Each formula is generated by `zig build mac-release` in Zigbox/zigbox.
